# PC-Diagnostics-tool
PC Diagnostic Tool is a Python-based application designed to analyze and monitor key system parameters of a personal computer, providing detailed reports and live visualizations of performance metrics. This project showcases my ability to work with system-level data, build interactive GUIs, and generate insightful diagnostics — a strong demonstration of my programming and problem-solving skills.

Key Features
-Comprehensive system information gathering (CPU, RAM, disk health)
-Real-time performance monitoring with live charts (CPU and RAM usage)
-Detailed diagnostic report generation and export
-User-friendly GUI built with PyQt5 for intuitive interaction
-Modular code architecture emphasizing clean, maintainable Python code

To run GUI use the command in the terminal : python -m GUI.main_window
